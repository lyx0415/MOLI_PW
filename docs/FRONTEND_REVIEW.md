# 前端视觉与交互审查

日期：2026-10-28。本次针对既有 Vue 前端进行调整，继续使用现有图形组件和依赖。

## 信息层级

| 层级         | 用途                         | 表现                                     |
| ------------ | ---------------------------- | ---------------------------------------- |
| 公共主导航   | 首页、场景、发现、入驻、帮助 | 顶部吸附，浅绿底指示当前父栏目           |
| 个人空间     | 账号、订单、角色工作台       | 角色化次级导航，细下划线指示当前入口     |
| 场景栏目     | 全部与六类服务场景           | 横向导航、下划线，窄屏可滚动             |
| 页面内部筛选 | 游戏、方式、城市、预算、排序 | 游戏按钮与输入控件；已选条件可单独移除   |
| 主要行动     | 寻找搭子、提交或确认         | 深绿实心按钮；次要操作使用浅底或文字链接 |

首页的内容顺序为：品牌与搜索 → 六类场景 → 游戏 → 陪玩 → 服务流程 → 入驻与公告。卡片展示真实接口数据，未添加虚假人数、销量或评价。

## 交互与异常处理

- 发现页 URL 是筛选状态来源，切换条件重置分页；搜索输入保留 300ms 防抖。迟到请求不能覆盖当前结果，组件卸载时清理计时器。
- 刷新、复制链接及从详情返回时恢复条件。切换筛选不跳回页顶，浏览器后退仍优先恢复已有滚动位置。
- 维持加载骨架、空结果、接口失败与重试入口；已选条件支持逐个移除或全部清除。
- 账号菜单、手机导航避免同时展开；导航支持 Escape、焦点恢复、外部点击关闭和路由切换关闭。
- 按钮筛选使用 `aria-pressed`；导航标记当前栏目，提供主要内容跳转。保留系统减少动画偏好。
- 登录、角色权限、支付、预约与售后业务继续使用原有后端校验。
